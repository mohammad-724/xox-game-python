# ❌ XOX Game (Tic-Tac-Toe) ⭕

A simple, interactive terminal-based Tic-Tac-Toe game written in Python. Play a classic game of strategy against a computer bot right inside your command line.

## 🚀 Features
* **Human vs. Bot**: Play as `X` against a randomized computer bot playing as `O`.
* **Input Protection**: Prevents crashes if you enter invalid numbers or letters.
* **Auto-Update**: The 3x3 game board automatically prints fresh after every turn.

## 🛠️ How to Run
1. Open your terminal or command prompt.
2. Run the game using this command:
   ```bash
   python xox_game.py
   ```

## 🎮 How to Play
Type a number from **1 to 9** to place your mark on the corresponding board spot:

```text
 1 | 2 | 3 
---|---|---
 4 | 5 | 6 
---|---|---
 7 | 8 | 9 
```
Connect three marks in a row (horizontally, vertically, or diagonally) to win!
